# Mo examples
Code to get a feel for the Mo syntax and to test the compiler with. Each file shows one feature of the language, written according to the spec in [mo/notes/INTRODUCTION.md](https://github.com/MoLanguage/mo/blob/main/notes/INTRODUCTION.md).

The compiler doesn't implement everything yet, so not every file parses. Which parts are missing is tracked in [mo/notes/ROADMAP.md](https://github.com/MoLanguage/mo/blob/main/notes/ROADMAP.md).

Try a file with the `mo` binary from the [compiler repository](https://github.com/MoLanguage/mo):

``mo -p <path_to_file> --print-ast``

## Ideas folder
The /ideas folder holds sketches of features that are still open questions (see [mo/notes/IDEAS.md](https://github.com/MoLanguage/mo/blob/main/notes/IDEAS.md)). They are not part of the spec and aren't expected to parse.
